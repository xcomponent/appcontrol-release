    ClusterMode¶

    How a multi-host component is represented. Aggregate trusts an external aggregator (F5, Oracle SCAN). FanOut makes each member a first-class entity with its own FSM and history.

    Source comment: How cluster members contribute to the parent component's state.

    Variant Wire format Numeric value Description
    Aggregate "aggregate" — External aggregation: the component-level check_cmd is assumed to already aggregate over hosts (F5, Oracle SCAN, JMX, etc.). cluster_size / cluster_nodes (V035) are cosmetic.
    FanOut "fan_out" — Per-member execution: each cluster_members row is a first-class entity with its own agent, commands, FSM and history.

    ClusterHealthPolicy¶

    When cluster_mode = FanOut, how to derive the parent component's state from member states.

    Source comment: Policy that derives the parent component's state from member states (only meaningful when cluster_mode = FanOut).

    Variant Wire format Numeric value Description
    AllHealthy "all_healthy" — All RUNNING → RUNNING; any non-RUNNING → DEGRADED; 0 RUNNING → FAILED.
    AnyHealthy "any_healthy" — Any RUNNING → RUNNING; 0 RUNNING → FAILED.
    Quorum "quorum" — count(RUNNING) ≥ ⌈N/2⌉+1 → RUNNING; else DEGRADED; 0 RUNNING → FAILED.
    ThresholdPct "threshold_pct" — %RUNNING ≥ min_healthy_pct → RUNNING; ≥50% → DEGRADED; else FAILED.
