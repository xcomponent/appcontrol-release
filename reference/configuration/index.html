    Configuration reference¶

    Auto-generated by scanning crates/{backend,agent}/src/config.rs. Run scripts/docs/regen.py to refresh.

    Configuration comes from environment variables (backend, agent) or CLI flags (gateway). Settings exposed through the UI (organisation heartbeat_timeout_seconds, per-app retention overrides, etc.) live in the database and are not covered here — see the User Guide.

    Quick start for a production-ready deployment:

    export APP_ENV=production
export JWT_SECRET=$(openssl rand -base64 48)
export DATABASE_URL=postgresql://appcontrol:STRONG_PASS@db.internal:5432/appcontrol
export CORS_ORIGINS=https://appcontrol.example.com
export HA_MODE=true                       # only if running multiple backend replicas
export LOG_FORMAT=json                    # for SIEM ingestion
export RETENTION_ACTION_LOG_DAYS=1825     # 5 years — DORA
export RETENTION_CHECK_EVENTS_DAYS=365    # 1 year

    Agent¶

    Agent configuration is read from a YAML file (default location: /etc/appcontrol/agent.yaml on Unix, C:\\ProgramData\\AppControl\\agent.yaml on Windows). Every key can be overridden by an environment variable. The variables below are the env-override surface.

    Source: crates/agent/src/config.rs. 12 variables.

    Env var Default Allowed values Description
    AGENT_ID (none — unset means feature off / required in production) auto UUID
    AGENT_MODE (none — unset means feature off / required in production) active advisory
    DATA_DIR (none — unset means feature off / required in production) directory path Where the agent stores its buffer database, enrolment cert, and agent.id. Defaults to /var/lib/appcontrol (Unix) or C:\\ProgramData\\AppControl (Windows).
    GATEWAY_RECONNECT_SECS (none — unset means feature off / required in production) seconds Sleep between gateway-reconnect attempts.
    GATEWAY_URL (none — unset means feature off / required in production) wss://gateway:4443 Single gateway URL. Legacy; prefer GATEWAY_URLS for failover.
    GATEWAY_URLS (none — unset means feature off / required in production) wss://gw1:4443,wss://gw2:4443 Comma-separated list of gateway URLs for failover. The agent walks them per the failover_strategy (default ordered) and re-tries the primary every primary_retry_secs.
    PROGRAMDATA (none — unset means feature off / required in production) (undocumented — add to scripts/docs/gen_configuration.py::ANNOTATIONS)
    TLS_CA_FILE (none — unset means feature off / required in production) PEM path CA bundle used to verify the gateway's server cert.
    TLS_CERT_FILE (none — unset means feature off / required in production) PEM path Agent's client certificate.
    TLS_ENABLED (none — unset means feature off / required in production) true false
    TLS_INSECURE (none — unset means feature off / required in production) true false
    TLS_KEY_FILE (none — unset means feature off / required in production) PEM path Agent's client private key.

    Gateway¶

    The gateway is configured via CLI flags rather than env vars. The authoritative list is crates/gateway/src/main.rs. The common flags:

    Flag Default Description
    --bind 0.0.0.0:4443 Address the gateway listens on for inbound agent WebSocket connections.
    --backend-url wss://localhost:8080/ws/gateway Backend endpoint the gateway dials.
    --cert /etc/appcontrol/gateway.crt Server certificate presented to agents.
    --key /etc/appcontrol/gateway.key Server private key.
    --ca /etc/appcontrol/ca.crt CA bundle used to verify agent client certs (mTLS).
    --name hostname Gateway display name, surfaced in the UI.
    --rate-limit-msgs-per-sec 200 Per-agent inbound message rate limit.

    Run gateway --help against the binary you ship to get the version-specific flag list.
