    Auto-generated from migrations/V*.sql. Run scripts/docs/regen.py to refresh.

    Notes¶

    • check_events is partitioned by day (PostgreSQL) — see migration V005 and the partition-creation logic in the backend. Retention drops whole partitions rather than deleting rows.
    • UUIDs are UUID (native) on PostgreSQL and TEXT (with DbUuid codec) on SQLite. Application code uses uuid::Uuid; the codec is transparent.
    • JSONB columns are JSONB on PostgreSQL and TEXT (with DbJson codec) on SQLite.
    • See Backup & restore for pg_dump recipes that respect the partition layout.
